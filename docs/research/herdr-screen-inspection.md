# Windows Herdr 화면 확인

Windows에서 실행 중인 Herdr의 Files 패널이나 터미널이 실제로 어떻게 보이는지는 `herdr-app shot`으로 확인할 수 있다. Windows 설치본 Herdr App 0.1.18 및 hc 0.1.22에서 확인했다. `herdr-app --skill`로 설치된 버전의 안내를 볼 수 있다. [Herdr 공식 가이드](https://herdr.dev/guide/) · [배포본 README](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/README.md#L100-L115) · [Windows 배포 정보](https://releases.herdr.dev/app/latest.json)

## 화면과 상태를 확인하는 명령

- `herdr-app shot [file.png]`은 실행 중인 창의 현재 렌더링을 물리 픽셀 크기의 PNG로 저장하고 절대 경로를 출력한다. 기본값은 현재 폴더의 `herdr-shot.png`다. 캡처에는 Herdr 내부의 패널, 터미널, 팝업과 오버레이가 들어간다. 배포본 가이드에 따르면 창이 가려지거나 최소화되어도 캡처할 수 있으며, 첫 프레임 이전이나 GPU 복구 중에는 오류를 반환한다. 구현은 창에 반영할 대기 중인 갱신을 처리해 프레임을 읽는다. 디렉터리 조회 같은 비동기 작업은 완료 시점에 다시 캡처해 확인한다. [배포본 화면 캡처 가이드](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/defaults/AGENTS.md#L67-L76) · [PNG 저장](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/src/control.rs#L148-L174) · [렌더링 동기화](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/vendor/gpui-pre/src/window.rs#L7634-L7669)
- `herdr-app status`는 레이아웃, 포커스, 오버레이, 확대 상태, 설정이나 모드 오류를 JSON으로 보여 준다. `herdr-app ls`는 space, 탭, 터미널을 나열한다. 격리 창을 검사할 때는 창을 띄울 때 쓴 `HERDR_APP_HOME`을 두 명령과 `shot`에 동일하게 지정한다. Files의 표시 경로와 행은 PNG에서 읽는다. [배포본 상태 조회 가이드](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/defaults/AGENTS.md#L733-L744) · [CLI 구현](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/src/control.rs#L73-L125)
- `herdr-app commands`는 실행 중인 창 없이도 명령과 인자를 나열한다. `herdr-app do <command> [args]`는 열린 창에 등록된 동작을 실행한다. 예를 들어 `herdr-app do space.select --id <id>`로 space를 선택하거나 `herdr-app do app.palette`로 명령 팔레트를 토글한 다음 `shot`으로 결과를 확인할 수 있다. 클릭 위치나 키 바인딩 자체를 검증할 때는 실제 입력과 화면을 함께 관찰한다. [배포본 명령 레퍼런스](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/docs/commands.md#L3-L18) · [space 선택](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/docs/commands.md#L178-L186) · [팔레트](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/docs/commands.md#L533-L537)
- `hc read <terminal> --lines 0`은 터미널의 현재 표시 텍스트를 읽는다. `hc get <terminal> --json`의 `cwd`는 시작 디렉터리이며 현재 디렉터리는 코어가 파악한 경우 `foreground.cwd`에 들어간다. 터미널에서 이동한 경로는 프롬프트나 `Get-Location` 출력과 대조한다. [herdr-core 공식 문서](https://herdr.dev/core/) · [hc v0.1.22 상태와 화면 조회](https://github.com/herdrdev/herdr-core/blob/6e2984629fcd600b0165f69b2e5b0bda5985ec1c/crates/herdr-core/src/SKILL.md#L58-L76)

## Windows에서 확인한 결과

격리된 `HERDR_APP_HOME`의 창에서 `shot`이 1600×1025 PNG를 생성했다. 이미지에서 터미널 제목과 `cd` 직후 프롬프트는 `TerminalRoot`로 바뀌었고, SwiftTree에는 `StartRoot`와 `start-only.txt` 행이 표시됐다. `status`는 `swifttree` 레이아웃, 포커스된 pane과 빈 `errors` 배열을 반환했다. `hc read`에서도 프롬프트는 `TerminalRoot`였고, `hc get --json`은 시작 경로 `cwd`에 `StartRoot`, 현재 경로 `foreground.cwd`에 `TerminalRoot`를 반환했다. 헤더를 좁게 자른 OCR에서 `SwiftTree StartRoot`를 확인했다. 넓은 영역에서 OCR이 `start-only.txt`를 잘못 읽어 해당 행은 이미지에서 직접 확인했다. [PNG와 OCR 검증 절차](../verification/windows-native-ui.md) · [OCR 검사 스크립트](../../tests/assert_herdr_panel.py)

Windows GUI 실행 파일을 단독으로 호출하면 PowerShell이 먼저 반환할 수 있다. 명령 응답과 캡처 완료를 기다리는 PowerShell 예제는 검증 절차에서 관리한다. [CLI로 화면 검증](../verification/windows-native-ui.md#cli로-화면-검증) · [Windows 앱 진입점](https://github.com/herdrdev/herdr-app/blob/9a9ae13d998e6ed74c76e8eb13bdeb2e1420f50c/src/main.rs#L1-L2) · [PowerShell Start-Process](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/start-process#-wait)

## Windows 시스템 UI와 Linux 검증

Windows 폴더 선택기처럼 별도 창에 표시되는 OS UI는 해당 창이나 디스플레이를 Windows Graphics Capture로 캡처할 수 있다. 화면 변화가 언제 처음 나타났는지 측정하는 기존 검증은 Windows Graphics Capture의 프레임 시각을 쓴다. [Microsoft 화면 캡처](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/screen-capture) · [Windows 검증 절차](../verification/windows-native-ui.md#windows-외부-변경-감시-검증)

Herdr 소스의 Linux용 `scripts/sandbox`는 Weston과 Xwayland로 헤드리스 디스플레이를 띄우고 별도의 앱 홈과 코어를 쓴다. `scripts/sandbox up`으로 시작하고 `shot`으로 창을 캡처하며 `click`과 `key`로 창에 입력을 보낼 수 있다. 작동하는 Vulkan 드라이버가 필요하다. 이 환경의 캡처는 Linux 빌드의 모드 렌더링과 동작을 검증하는 데 쓴다. Windows의 NTFS 경로, 폴더 선택기 또는 Windows 창에 연결된 SSH 패널을 검증할 때는 Windows에서 실행 중인 Herdr 창을 캡처한다.
